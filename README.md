# Prehisteria

An original 16-bit-style caveman platformer for the browser — you play **Brko**, who
runs, jumps, crouches, clubs prehistoric critters, and hoovers up food for points.

Inspired by the *feel* of early-90s DOS platformers, but a wholly original game: original
engine, original pixel art, original characters. Not a copy of any existing game and not
an emulator.

## Run it

```bash
npm install
npm run art        # (re)generate the original pixel-art PNGs into public/
npm run dev        # start Vite dev server, open the printed URL
npm run typecheck  # strict TS must pass — the quality bar
npm run build      # production build to dist/
```

## Tech

- **Vite + TypeScript (strict)**, no game-engine dependency — a small hand-written
  Canvas 2D engine.
- **Fixed-timestep** simulation with an accumulator; rendering interpolation-free but
  decoupled from physics.
- **Multi-layer tilemaps** — dense jungle background tiles behind the collision layer,
  for a lush backdrop rather than thin parallax.
- **Original art** generated by `scripts/gen-art.py` (dependency-free PNG writer).
- **Procedural Web Audio** SFX — no audio asset files.
- **localStorage** high-score table (`prehisteria-*` keys); a clean seam is left for a
  server-backed leaderboard later.
